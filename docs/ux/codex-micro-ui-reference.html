设计原则

硬件先于装饰

键位必须保持官方设备的 4×4 空间关系。第一排是旋钮、两个 Agent Key、摇杆；第二排承载其余四个 Agent Key。

状态色不承担选择态

蓝、绿、琥珀和红只表达任务状态。当前选中项使用浅鼠尾草背景和边框，避免语义混淆。

键帽像实体，不像按钮

使用乳白渐变、顶部内高光、3px 底部硬边和低透明投影。默认圆角为 9px，不使用高饱和品牌色填充整颗键。

信息和模型分栏

左侧展示可形成肌肉记忆的硬件模型，右侧展示任务标题。不要把长标题压进 62px 键帽。

核心设计令牌

键帽尺寸--key-size: 62px

WPF 实现当前为 58px，外部状态光场为 72px。

键间距--key-gap: 5px

在 820×360 浮层中可放宽到 8px。

键帽圆角--radius-key: 9px

面板圆角固定为 24px。

任务卡片min-height: 57px

双栏展示，标题保持单行省略。

Web 实现契约

<div class="key agent-key"
     data-status="thinking"
     aria-label="Agent Key 1：思考中">
  <span>↑</span>
  <i class="status-dot"></i>
</div>

实现检查清单

  • 状态通过 data-status 设置，不在组件上写行内颜色。
  • 支持 prefers-reduced-motion，关闭 Thinking 呼吸动画。
  • 任务标题必须有省略和完整的辅助功能名称。
  • 窄屏允许硬件模型与任务面板上下排列，不改变键位顺序。
  • 图标优先使用项目内矢量资源，文本符号只用于规范页示意。
视觉基准参考： OpenAI · Codex Micro。 本规范用于 Agent Controller 内部实现对齐，不复制官方页面内容或品牌素材。
