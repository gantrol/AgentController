# AgentController 设计系统梳理

基于 `app/Themes`、主窗口、设备页和字号缩放代码的静态审查，以及用户提供的截图。范围为 AgentController Windows 主程序；Codex Micro 的独立视觉探索另行维护。以下区分现有实现、本次修正与后续建议。

## 当前视觉方向

浅色工作台、冷灰白底、石墨色文字、鼠尾草绿强调。外壳通过半透明渐变、亮边和柔和阴影表达材质；内容区主要用留白、细分隔线和选中底色组织信息。名称、图标和操作状态承担表达，不增加解释性界面文案。

## 组件库

Dev 模式（`--dev-instance`）入口：**设置 → 组件库**；普通模式隐藏入口。默认展示全部分类，也可以按分类筛选、搜索组件或资源名称。预览卡片可切换 280 / 360 / 440 像素宽度；重置会恢复展示样例的初始状态。

| 分类 | 展示内容 |
| --- | --- |
| 基础样式 | 语义色板、字号、间距、圆角、控件高度 |
| 操作控件 | 主按钮、次按钮、弱按钮、图标按钮、标题栏按钮、键帽按钮 |
| 输入控件 | 输入框、只读与禁用输入框、复选框、开关、滑块、下拉选择 |
| 导航 | 分段选择、连接式标签、侧边栏标签、操作菜单、径向菜单、父子侧边栏菜单 |
| 列表与滚动 | 实际任务条目、置顶与项目、空列表、长标题、横纵滚动、section 溢出 |
| 状态与反馈 | 事件行、状态点、任务状态灯、等宽数字、额度状态、提示、进度、动效 |
| 容器与材质 | 卡片及分隔变体、连接面板、浮层、提示面板、阴影 |
| 图标与按键 | Agent logo、侧边栏图标、手柄字形、按键尺寸、Agent 按键面板、手柄教程 |

样例直接引用运行中的主题资源和现有控件。任务条目使用共享 `Sidebar.Entry`，事件行使用共享 `Event.Row`，设备页也引用这两个模板。修改共享样式后，组件库与正式界面使用同一份实现。

默认、选中、禁用、只读等状态并排展示；悬停、按下、键盘焦点和滚动由真实控件响应用户操作。菜单等固定尺寸的组合组件按比例缩小展示。展示数据为本地样例，不执行 Agent 命令。

独立启动：

```powershell
npm run storybook:controller
```

启动脚本先构建到独立目录 `artifacts/controller-storybook`，再通过 `dotnet` 控制台宿主打开组件库。构建日志、启动异常会保留在终端；窗口首次渲染完成后输出 `Component gallery ready.`。

也可直接运行已构建程序：

```powershell
dotnet .\artifacts\controller-storybook\bin\AgentController\debug\AgentController.dll --dev-instance --component-gallery
```

独立模式读取现有语言与字号偏好，不初始化手柄、Agent 会话或主程序托盘，可与主程序同时打开。源码入口为 `app/Views/ComponentGalleryWindow.xaml` 和 `app/Presentation/ComponentGalleryCatalog.cs`；新增可复用组件时，在目录中补充对应样例。

共享模板依赖的资源应先加载：提示样式集中在 `Themes/Controls/Tooltips.xaml`，位于事件模板 `Status.xaml` 之前，避免独立组件实例化时找不到 `Tooltip.HitRegion`。

## 截图问题与本次修正

### 最近事件基线

原实现用两个独立 TextBlock 并做垂直居中。等宽字体和界面字体的字面高度不同，文本框居中不能保证文字基线一致。

改为一个 TextBlock 内的时间 Run、间隔和正文 Run，共用文字基线。时间保留等宽字体，间距使用一个 em 空格并跟随字号；长内容单行省略，提示中保留完整内容。`Text.EventLine` 统一字号、字重、颜色与截断行为。

### 滚动条

原主题没有 ScrollBar 模板，横向 section 栏、任务列表和事件区使用系统默认滚动条，出现粗灰轨道与箭头。横向滚动条位于标签与面板之间，还破坏了连接标签的轮廓。

新增 `app/Themes/Controls/Scrolling.xaml`：

- 全局使用透明轨道、圆角细滑块，去掉两端箭头。
- 滚动条命中宽度 12，滑块可见厚度 4，滑块最短长度 24；尺寸与边距来自 token。
- 默认使用中性灰，悬停与拖动使用深浅两级强调色。
- 保留拖动、轨道翻页和滚动容器原有滚动行为。
- `ScrollViewer.SectionTabs` 保留横向连接标签模板；设备页侧边栏已改用按宽度换行的分类按钮，避免末项只显示半个。

源码编译通过；未进行 UI 手动验证。不同 DPI、输入方式和主题模板组合下的实际外观仍需后续授权验证。

## 设备页状态表达（2026-10-04）

状态沿用运行时的来源与输入条件，界面按以下职责展示：

- 控制会话：固定显示桥接关闭、断连、待解锁、等待回中、就绪、后台控制或暂停的简短状态。状态点仅表示会话可用性，不表示 Micro 操作成功。
- Micro：当前值与操作状态分行展示；打开、关闭、应用中和错误不再写入当前值。读回未确认时清除值，显示“未读取”与未确认状态；缺少模型目录不推断为 Agent 未在前台。
- 右栏直接呈现 Codex 列表与最近事件，不常驻右摇杆模式、未读取值或模型摘要。手柄控制状态位于顶部开关旁；菜单打开时在手柄区下方显示当前选项与待确认状态，错误反馈仍保留。菜单中的选项不代表已应用的模型。
- 语音：快捷入口跟随开始、录音、结束和失败结果更新名称。停止失败保持明确反馈，进行中及错误文字不随入口禁用而淡出。物理手柄与鼠标入口保留各自的执行条件。
- 分层：页签保留当前预览，组合层实际生效时单独显示短状态；松开、取消或重置后清除生效状态。手柄图用静态浅色显示预览，实体输入保留实色反馈。
- 按键：悬停、关联高亮、按下、待确认与键盘焦点分别表达。待确认使用警告色边框，并提供无障碍状态；按下不降低内容透明度。
- 上下文提示继续承接鼠标与键盘焦点信息。最近事件移除不绑定运行状态的装饰点。

实现集中在设备页与教程 ViewModel、对应视图及 `Themes/Controls/ControllerInput.xaml`、`Status.xaml`。新增状态文案通过中英文 catalog 维护；输入路由、确认次数与长按时限沿用现有逻辑。

## 设备页操作入口（2026-10-04）

- 移除手柄面板下方的六项快捷操作，手柄图与按键区占用左侧完整高度。
- 基础页补齐 A 打开任务、B 关闭 / 撤回与 Y 动作面板；LT、X 和 Menu 复用原有入口。按键区按双列排列，并显示动作名称。
- 手柄图在左侧垂直居中；右侧保留 Micro 状态、任务列表与最近事件。按键区内容超出高度时独立滚动。
- 语音进行中与失败状态位于手柄区下方，切换手柄页签后仍可见；闲置时隐藏，继续使用既有语言资源与状态颜色。

## 托盘菜单（2026-10-04）

托盘沿用 WinForms 原生菜单的打开、关闭和键盘导航，由 [TrayMenu.cs](../../app/Themes/Controls/TrayMenu.cs) 统一绘制。表面、文字、分隔线与浅绿高亮读取现有语义色 token；表面从白色过渡至浅绿灰，采用 8 DIP 圆角轮廓与一像素细边，保留系统菜单阴影，呼应 Micro 悬停提示的轻浮层质感。去除空图标栏和分隔线的双线效果，选中行使用 4 DIP 圆角。菜单内距、行内距及最小宽度按显示器 DPI 缩放，文字在每次打开时读取应用字号，并保留系统菜单字号下限。高对比度模式使用系统字体、原生渲染器和矩形轮廓。

## 首页侧边栏折叠（2026-10-04）

- 首页右上角保留收起 / 展开按钮。右侧信息栏从 410 DIP 收至 44 DIP，切换页面时保留当前状态，重启后默认展开。
- 手柄区随剩余宽度扩展，内部内容最大宽度 1120 DIP、手柄图最大宽度 640 DIP。按键区在 288–432 DIP 范围内分配宽度，按可用空间从两列换成三列。手柄图垂直居中，按键区顶部对齐，避免换列时整组上下跳动；溢出时独立滚动。
- 宽度使用 `Duration.Base`（180 ms）与 `Ease.Out`，内容透明度使用 `Duration.Fast`（120 ms）。动画期间右栏内容保持完整宽度并裁切，避免任务文本反复换行；连续点击从当前宽度和透明度继续过渡。
- 系统关闭客户端动画或开启高对比度时直接切换。收起后隐藏内容不参与键盘导航，内部焦点移到展开按钮；按钮保留焦点环及中英文操作名称。
- 语音进行中与错误反馈固定在手柄区下方，不随右栏收起或展开而移动。
- 基础页仅在按键区实际可容纳三列时合并消息方向键：前三项为“浏览任务”“模型设置”“浏览消息”，两个摇杆与十字键共用 84 × 84 DIP 图形区域及标题基线。两列时恢复独立的上一条 / 下一条消息键及原有顺序，不把合并十字键挤到第二行。每列含边距占 130 DIP，判断使用扣除滚动条后的可用宽度。
- 换列由 `TutorialActionsPanel` 负责。常驻按键使用 180 ms 缓出平移，上下键与合并十字键用 120 ms 淡出 / 淡入；快速反向切换从当前显示位置和透明度接续。退出的控件立即停止接收输入，键盘焦点转交给对应方向；保留原有点按、长按与关联高亮。系统减少动画或高对比度时直接切换。

## 主窗口尺寸（2026-10-04）

- 主窗口不支持最大化，移除标题栏最大化按钮，禁用标题栏双击及系统最大化命令。
- 默认尺寸保持 1220 × 800 DIP，最小尺寸保持 1060 × 690 DIP，最大尺寸限制为 1440 × 960 DIP；保留范围内的边缘拖拽缩放、最小化、托盘恢复和侧栏折叠。尺寸随系统显示缩放比例换算，窗口外壳沿用普通窗口的边距与圆角。

## 改进优先级

| 优先级 | 发现 | 建议 |
| --- | --- | --- |
| P1 | 字号可缩放，但按钮、标签及部分区域仍固定高度 | 明确字号与密度的关系，正文控件使用最小高度和内距，让内容撑开；品牌图标和窗口按钮单独保留固定尺寸 |
| P1 | 中英文字体和等宽字体混用时缺少统一排版规则 | 定义时间＋正文、图标＋标题、标题＋副标题等常见组合；同一行文字按基线排版，图形按光学中心对齐 |
| P1 | 不同列表各自处理截断 | 侧边栏已换行并使选中项可见；继续统一其他列表的“省略＋完整提示”规则 |
| P1 | TextBox、普通 CheckBox 的主题只覆盖部分属性，仍依赖系统默认外观 | ComboBox 与水平 Slider 已补齐模板；继续完善其余输入控件状态 |
| P1 | 颜色、圆角和尺寸散落在 Shell、Segments 与视图；还有旧资源别名 | 把材质配方、边框、圆角及控件尺寸归入明确的语义 token；逐步替换局部常量和旧别名 |
| P1 | 字号变化会改变按钮内容所需空间 | Button.Base 与水晶按钮的 Padding 已生效；继续检查固定宽度控件的裁切与命中区域 |
| P2 | 多处直接写图标尺寸、路径和线宽，箭头还有字符与路径两种实现 | 建立统一图标资源和尺寸档位；品牌 logo 保留自身比例，功能图标统一线宽与视觉重量 |
| P2 | hover 有时降低整个控件透明度，有时换背景；最近事件标题的绿色点固定不变 | 建立状态矩阵，减少交互时文字亮度变化；固定装饰点与真实连接、运行状态明确区分 |
| P2 | 已有焦点环、可访问名称和部分系统动画开关处理，但高对比度与完整状态覆盖缺少统一规则 | 补齐可访问性规则；颜色之外继续使用轮廓、位置或图形表达状态；统一遵循系统动画偏好 |
| P2 | 已建立主程序组件库与分类入口 | 持续补充组件状态表和尺寸规则，新组件同步进入组件库 |
